⚽ วิธีใช้งาน Football Data API

🎯 สำหรับนักพัฒนาเว็บไซต์: คู่มือนี้จะแสดงวิธีการเรียกใช้ API เพื่อดึงข้อมูลฟุตบอลไปแสดงในเว็บไซต์ของคุณ

📋 API Endpoints ที่พร้อมใช้งาน

1. ดึงข้อมูลแมตช์วันนี้

GET http://localhost:3001/api/data/matches/today

คำอธิบาย: ดึงข้อมูลการแข่งขันฟุตบอลในวันนี้

2. ดึงข้อมูลแมตช์ตามวันที่

GET http://localhost:3001/api/data/matches/date/{วันที่}

คำอธิบาย: ดึงข้อมูลการแข่งขันในวันอื่นๆ

ตัวอย่าง:

  • /api/data/matches/date/0 = วันนี้
  • /api/data/matches/date/1 = พรุ่งนี้
  • /api/data/matches/date/2 = มะรืนนี้

💻 วิธีเรียกใช้งานใน JavaScript

🔹 วิธีที่ 1: ใช้ fetch() API

// ดึงข้อมูลแมตช์วันนี้ async function getMatchesToday() { try { const response = await fetch('http://localhost:3001/api/data/matches/today'); const data = await response.json(); if (data.success) { console.log('จำนวนแมตช์:', data.totalMatches); console.log('รายการแมตช์:', data.matches); // แสดงผลในเว็บไซต์ displayMatches(data.matches); } } catch (error) { console.error('เกิดข้อผิดพลาด:', error); } } // ฟังก์ชันแสดงผลแมตช์ function displayMatches(matches) { const container = document.getElementById('matches-container'); container.innerHTML = ''; matches.forEach(match => { const matchDiv = document.createElement('div'); matchDiv.className = 'match-item'; matchDiv.innerHTML = ` <h3>${match.homeTeam} vs ${match.awayTeam}</h3> <p>⏰ ${match.time}</p> <p>📅 ${match.date}</p> <p>🏆 ${match.league}</p> `; container.appendChild(matchDiv); }); }

🔹 วิธีที่ 2: ใช้ jQuery AJAX

// ต้องโหลด jQuery ก่อน: <script src="https://code.jquery.com/jquery-3.6.0.min.js"></script> $.ajax({ url: 'http://localhost:3001/api/data/matches/today', method: 'GET', dataType: 'json', success: function(data) { if (data.success) { $('#total-matches').text(data.totalMatches); var html = ''; data.matches.forEach(function(match) { html += '<div class="match">'; html += '<h4>' + match.homeTeam + ' vs ' + match.awayTeam + '</h4>'; html += '<p>' + match.time + ' | ' + match.date + '</p>'; html += '</div>'; }); $('#matches-list').html(html); } }, error: function(xhr, status, error) { console.error('Error:', error); } });

⚠️ สิ่งที่ต้องระวัง

CORS Policy: API นี้ได้เปิดใช้งาน CORS แล้ว สามารถเรียกใช้จากเว็บไซต์อื่นได้โดยตรง
Cache: ข้อมูลจะถูก cache ไว้ 2 นาที เพื่อความเร็วและลดการใช้ทรัพยากร
Real-time: ข้อมูลจะถูกอัพเดทแบบ real-time จากแหล่งข้อมูลต้นทาง

🚀 ขั้นตอนการเริ่มใช้งาน

1. เริ่ม API Server: เปิด Terminal และรัน node server.js
2. ตรวจสอบ: เปิดเบราว์เซอร์ไปที่ http://localhost:3001
